# XP-420B 网站直连打印设计

**日期：** 2026-09-08
**状态：** 已确认并批准
**目标工作树：** `codex/print-workflow-improvements`

## 1. 背景

当前网站使用 `window.print()` 把程序生成的打印页交给浏览器。浏览器、Windows
驱动和打印机可能对纸张尺寸、方向、边距再次解释，已经出现一条唛头内容被分页到
两张实体标签上的问题。

现场使用 Windows 电脑、Xprinter XP-420B USB 热敏标签打印机和
`100 × 75 mm` 标签纸。用户接受首次手动安装一次本地打印助手，要求后续在网站内
完成打印机选择、范围、份数、偏移和预览，并直接打印，不弹出浏览器打印窗口。

XP-420B 为 203 DPI 打印机，支持 TSPL、EPL、ZPL 和 DPL。第一版使用 TSPL
位图打印，把网页排版结果固化为一个与实体标签一一对应的位图，绕过浏览器分页。

## 2. 目标

- 一条唛头始终对应一张实体标签，不能因页面溢出被拆成两张。
- 网站拥有完整打印界面；本地助手正常工作时不显示独立打印窗口。
- 打印助手自动发现 Windows 打印队列中的 XP-420B，并记住上次选择。
- 支持打印范围、份数、逐份打印、方向、水平偏移、垂直偏移和实时预览。
- 固定验证 `100 × 75 mm`、203 DPI 的首个打印配置，同时保留未来扩展其他尺寸的边界。
- 打印数量只有一个事实来源，避免程序数量与驱动份数相乘。
- 连接、缺纸、离线、部分发送和状态不明时给出可恢复且不会诱发重复打印的反馈。
- 唛头、图片和草稿继续在用户电脑内处理，不上传给打印服务。

## 3. 非目标

- 第一版不支持 macOS、Linux、手机或非 Xprinter 打印机。
- 第一版不通过 WebUSB 直接占用 USB 设备。
- 第一版不制作通用标签编辑器；继续使用网站现有编辑和预览能力。
- 第一版不承诺从 Windows 打印队列获知纸张已经物理输出，只区分“未发送”、
  “已提交到打印队列”和“状态不明”。
- 第一版不自动重试状态不明的任务。
- 不移除现有浏览器打印实现；它仅作为明确标注的应急备用入口。

## 4. 方案选择

### 4.1 采用：自建 Windows 打印助手 + TSPL 位图

网站生成逐标签位图，本地助手使用 Windows 打印队列向 XP-420B 发送原始 TSPL。
每张实体标签都拥有独立的 `PRINT 1,1` 语义，浏览器不参与分页。

采用该方案的原因：

- 可直接控制标签点阵、纸张尺寸、方向、偏移和每次打印数量。
- 能保留现有网页对文字、图片、字号、旋转和位置的排版结果。
- 不依赖第三方桌面软件的授权、签名服务或生命周期。
- 可针对 XP-420B 的真实走纸和传感器行为做硬件测试。

### 4.2 未采用：QZ Tray

QZ Tray 可以枚举打印机并发送原始或像素打印任务，集成速度较快，但会引入第三方
安装包、消息签名和潜在授权成本。它可以作为实现受阻时的备选，不作为首版依赖。

### 4.3 未采用：WebUSB

WebUSB 的浏览器支持和设备兼容性有限，Windows 驱动还可能已经占用打印机接口。
它需要浏览器设备授权，也不符合仓库环境对稳定打印的要求。

## 5. 总体架构

系统增加两个边界清晰的模块：

1. **网站打印客户端**：React/TypeScript，实现打印对话框、精确点阵渲染、任务构建、
   助手发现、状态展示和恢复操作。
2. **Windows 打印助手**：`.NET 10` Windows 托盘应用，以自包含 x64 安装包分发，
   通过本机安全接口接收结构化任务、枚举打印机、生成 TSPL 并写入 Windows 打印队列。

打印助手安装后随 Windows 登录启动。正常打印时它只在托盘后台运行；网站连接失败、
首次配对或用户主动打开托盘菜单时，助手才显示原生窗口。

### 5.1 本机通信

- 助手只监听 loopback 地址，不监听局域网网卡。
- 生产通信使用安装器配置并受信任的 localhost TLS 端点。
- 助手只允许生产网站的精确 Origin；开发 Origin 仅在开发构建中启用。
- 首次配对由助手显示一次本机确认，之后网站保存配对标识，助手保存经 DPAPI 保护的
  授权记录。
- 每个请求携带配对凭据、协议版本和唯一请求 ID。
- 接口只接受预定义的健康检查、打印机列表、配置、校准、提交任务和查询状态操作；
  不接受任意命令、脚本、文件路径或网络地址。

## 6. 精确渲染与 TSPL 输出

### 6.1 点阵尺寸

XP-420B 使用 203 DPI，即每毫米约 8 点。`100 × 75 mm` 标签固定渲染为
`800 × 600` 点。尺寸换算集中在纯函数中，不能由 CSS 像素、设备像素比或浏览器缩放
决定。

### 6.2 网站渲染

- 增加专用打印位图渲染器，复用现有 `PrintPages`、文字布局、打印区域、旋转和样式
  的领域数据，但不截图 DOM。
- 使用离屏 Canvas 按物理点阵绘制背景、边框、文字和图片。
- 字体加载完成后才能启用打印；字体失败时阻止发送并说明缺少的字体。
- 文字和图片最终转换为 1-bit 黑白点阵。默认使用自动阈值；图片标签可选择二值阈值。
- 渲染器必须在发送前验证所有有效像素位于 `800 × 600` 边界内；越界时留在对话框
  并提供“返回修改”，不能裁切后静默打印。

### 6.3 助手输出

助手验证收到的宽、高、位图长度和内容哈希，再生成与以下语义等价的 TSPL 任务：

- 设置 `100 mm × 75 mm` 纸张。
- 设置现场校准后的间隙纸或黑标传感器配置。
- 设置方向和点阵原点偏移。
- 清空打印缓冲区。
- 写入一张 `800 × 600` 的位图。
- 明确执行一次 `PRINT 1,1`。

准确的传感器校准指令和间隙参数不得凭经验硬编码；必须在真实 XP-420B 上验证后写入
打印机配置。更换纸卷后，网站可以请求助手执行一次纸张校准。

### 6.4 数量语义

- 现有 `PrintPlan` 继续按业务数量和张贴面数展开程序打印页。
- 打印范围作用于展开后的页序号。
- 对话框“份数”是对所选页的显式倍数，默认值为 1。
- “逐份打印”只在份数大于 1 时启用。
- 助手不使用 Windows 驱动的多份打印；它逐张发送，并确保每张仍是一次
  `PRINT 1,1`。
- 对话框在提交前显示公式：`所选页数 × 份数 = 将发送的实体标签数`。

## 7. 网站内打印对话框

打印对话框延续项目现有工业工作台视觉语言，并替换默认的浏览器打印入口。

### 7.1 左侧设置

- **打印助手状态**：未安装、启动中、正在连接、已连接、版本不兼容。
- **打印机**：列出 Windows 打印队列，优先并记住名称包含 `XP-420B` 的设备。
- **标签尺寸**：显示 `100 × 75 mm`；首版不可随意修改。
- **打印范围**：全部，或起始页和结束页。
- **打印份数**：正整数，默认 1；显示最终实体标签数。
- **逐份打印**：份数大于 1 时可用。
- **方向**：复用现有横向/纵向和单条旋转设置。
- **水平/垂直偏移**：使用毫米，限制在安全范围内，修改后立即更新预览。
- **打印效果**：文字默认二值；图片可选自动二值和自定义阈值。
- **纸张校准**：独立次要操作，不与正式打印混在同一次任务中。

### 7.2 右侧预览

- 按 `100:75` 比例显示最终点阵预览，而不是浏览器打印预览。
- 支持上一张、下一张和“第 N / 共 M 张”。
- 预览使用与发送任务相同的点阵结果，不能存在第二套排版计算。
- 显示安全边界和越界错误；辅助线不进入最终位图。

### 7.3 主要操作

- **取消**：关闭对话框并恢复触发按钮焦点。
- **直接打印**：只有助手已连接、打印机可用、范围有效且全部页面通过验证时才启用。
- 提交后按钮保持尺寸，显示固定忙碌状态，并阻止重复点击。
- 成功反馈使用“已向打印队列提交 N 张”，不宣称实体纸张已经打印完成。
- 现有浏览器打印放入“更多操作 > 浏览器打印（应急）”，不会自动触发。

## 8. 任务协议与防重复

每个任务包含：

- 协议版本、任务 ID、创建时间和网站版本。
- 目标打印机的稳定标识和显示名称。
- 纸张配置 ID、宽高、方向、偏移和传感器配置版本。
- 所选范围、份数、逐份顺序和预期实体标签总数。
- 每张页面的页序号、标签 ID、点阵尺寸、PNG/位图数据和 SHA-256 哈希。

助手按任务 ID 做幂等处理：同一任务重复提交时返回已有状态，不再次写入打印队列。
用户主动重新打印必须由网站生成新的任务 ID，并在状态不明时先显示警告。

任务状态为：`received`、`validating`、`submitting`、`submitted`、`partial`、
`failed` 或 `unknown`。助手持久保存最近任务摘要和每页提交结果，但不长期保存标签
位图；完成或超时后删除位图数据。

## 9. 错误和恢复

- **助手未安装**：显示下载与安装说明，不回退到浏览器打印。
- **助手未启动**：显示“启动打印助手”，通过已注册的自定义协议唤起后台进程，连接
  成功后仍使用网站对话框。
- **版本不兼容**：阻止打印并给出对应安装包，不允许忽略协议不兼容。
- **打印机不存在或离线**：保留全部设置，允许刷新打印机列表。
- **纸张配置未校准**：阻止正式打印，先完成独立测试页和校准流程。
- **某页验证失败**：一页也不提交，返回具体页码和原因。
- **部分提交**：显示已提交页码和第一张未确认页；允许用户从指定页创建新任务。
- **状态不明**：不自动重试，提示先检查打印机和队列，再由用户决定是否生成新任务。
- **网页刷新或关闭**：重新连接后使用任务 ID 查询状态，不能盲目重新提交。

## 10. 安装、启动和升级

- 助手以自包含 Windows x64 安装包分发，不要求用户另外安装 .NET Runtime。
- 首次安装需要用户手动运行并确认；生产安装包应使用代码签名证书。
- 安装器注册开机启动和 `labelprint://` 自定义协议，只用于启动助手或打开诊断页。
- 正常打印不跳转到自定义协议，也不弹出助手原生打印窗口。
- 网站启动时查询助手协议版本；版本不兼容时显示升级入口。
- 首版升级由用户下载安装新版；自动升级另行设计。

## 11. 代码组织

网站预计新增或调整：

- `src/domain/directPrinting.ts`：尺寸换算、任务模型、范围和数量计算。
- `src/domain/printBitmap.ts`：点阵渲染输入和纯计算边界。
- `src/services/printHelperClient.ts`：发现、配对、API 调用和状态查询。
- `src/features/DirectPrintDialog.tsx`：网站内打印对话框。
- `src/features/PrintBitmapPreview.tsx`：共享最终点阵预览。
- `src/App.tsx`：把现有打印入口接到直打流程，并保留应急入口。
- `src/styles.css`：复用现有令牌增加直打对话框布局和响应式状态。

打印助手预计新增：

- `print-helper/LabelPrintHelper.sln`
- `print-helper/src/LabelPrintHelper/`：托盘生命周期、本机 API、授权和配置。
- `print-helper/src/LabelPrintHelper/Printing/`：打印机发现、TSPL 编码和 Windows spooler。
- `print-helper/tests/`：协议、TSPL、幂等和故障恢复测试。
- `print-helper/installer/`：安装、开机启动、协议注册和卸载。

实际文件边界可在实施计划中依据现有代码进一步收敛，但不得把 TSPL 编码、网页 UI
和本机安全接口合并为一个不可独立测试的模块。

## 12. 测试与验收

### 12.1 自动化测试

- `100 × 75 mm @ 203 DPI` 精确转换为 `800 × 600` 点。
- 页码范围、份数和逐份顺序产生正确且唯一的实体标签序列。
- 越界、缺字型、错误尺寸和损坏位图在发送前被拒绝。
- 同一任务 ID 重复请求不会重复写入打印队列。
- TSPL 输出包含正确尺寸、位图字节数、原点、传感器配置和单次打印语义。
- 网站在未安装、未启动、离线、部分提交、失败和状态不明时显示正确恢复动作。
- 对话框具备标题、描述、焦点约束、Escape、焦点恢复和键盘可操作性。
- 模拟助手集成测试验证网站生成页数与助手接收页数完全一致。

### 12.2 真实硬件验收

在 XP-420B 和真实 `100 × 75 mm` 标签纸上依次验证：

1. 测试页与间隙/黑标校准。
2. 单条文字唛头：计划 1 张，实际只输出 1 张且内容不跨页。
3. 连续 10 条：计划、提交和实体输出均为 10 张。
4. 多行、最大字号、边框、旋转、图片和正负偏移。
5. 份数 2 与逐份打印顺序。
6. 打印机离线、缺纸、中途断开和网页刷新后的状态恢复。
7. Windows 重启后助手自动启动，网站自动连接。
8. 全流程不出现浏览器打印窗口。

硬件验收未通过前，不把直打入口标记为生产默认。针对“一条内容打印到两张纸”的
核心问题，验收必须保存打印任务摘要和实体标签照片作为证据。

## 13. 实施顺序

1. 建立网站与助手共享的版本化协议和模拟助手。
2. 用测试驱动实现点阵尺寸、范围/份数和 TSPL 编码。
3. 实现 Windows spooler 与 XP-420B 测试打印 CLI。
4. 在真实打印机上验证 `100 × 75 mm` 单张不跨页，再继续 UI 集成。
5. 实现网站内打印对话框和最终点阵预览。
6. 加入配对、TLS、Origin 限制、任务幂等和状态恢复。
7. 制作自包含安装包、开机启动和版本检测。
8. 完成自动化验证、真实硬件验收和受控启用。

## 14. 已确认决策

- 使用自建 Windows 打印助手，而不是纯浏览器打印。
- 使用网站内打印面板；助手正常打印时只在后台运行。
- 首个硬件目标为 Xprinter XP-420B。
- 首个纸张配置为 `100 × 75 mm`。
- 用户接受每台电脑首次手动安装一次打印助手。
- 目标是解决一条内容被浏览器分页到两张实体标签的问题。
