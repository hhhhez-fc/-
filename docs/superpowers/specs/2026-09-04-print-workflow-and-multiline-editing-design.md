# 打印流程与多行编辑改进设计

日期：2026-09-04  
状态：已与用户逐节确认

## 目标

在现有本地唛头打印工作台中完成以下改进，同时保证屏幕预览、打印检查和系统打印输出使用同一份排版结果：

1. 在唛头列表内直接修改打印数量，并移除编辑器中的“基础数量”。
2. 支持连续单击选择多行文字，统一修改样式、方向和位置；单击打印区域空白处清空选择。
3. 移除人工“校对完成”门槛，合法唛头可直接进入打印预览。
4. 在应用的打印预览窗口内循环旋转文字内容，纸张宽高与系统纸张方向保持不变。
5. 唛头进入打印检查窗口时即写入使用历史，而不是等到实际打印完成。
6. Excel 框选区域模式把本次所有框选内容合并到一条唛头中。
7. 内容超出打印区域时自动缩小字号；内容未超出时保留用户设置的字号。
8. 使用历史最多保存 20 个唛头，并支持再次使用。
9. 打印预览宽口增加可旋转字体但不旋转纸张方向。

## 非目标

- 不将排版系统改写为 Canvas。
- 不改变 Excel“按列批量导入”模式每行生成一条唛头的行为。
- 不从浏览器读取或推断打印机型号、驱动能力或系统打印份数。
- 不允许空内容、无效数量、错误尺寸或无法在最小字号下排入打印区域的唛头绕过打印验证。
- 不把当前多行选择写入本地草稿；它是当前编辑会话的临时状态。

## 总体方案

继续使用 React、TypeScript 和 DOM/CSS 打印。把容易分叉的行为下沉为纯领域函数：多行选择后的批量更新、整组位置移动、逐行字号求解、历史快照与去重、打印方向变换。屏幕预览与打印页都消费同一个逐行布局结果，避免重复计算导致字号或方向不一致。

打印继续使用固定物理尺寸的纸张画布，并保留动态 `@page size: 宽mm 高mm`，确保系统打印使用正确纸张方向。打印预览窗口为每个文字唛头提供循环旋转控制，按 `0° → 90° → 180° → 270° → 0°` 切换。该角度只作用于文字渲染，不交换纸张宽高，也不修改编辑区保存的原始行方向或位置。

## 数据模型

### 临时多行选择

`App` 保存 `selectedLineIds: string[]`，含义为当前唛头中已连续选择的文字行。规则如下：

- 单击一条未选文字行：把该行加入选择，并将它设为当前活动行。
- 单击一条已选文字行：保留当前选择，仅将它设为活动行，避免准备拖动时意外取消选择。
- 单击打印区域内不属于文字行或控制柄的空白：清空全部选择。
- 当前选择为空时，样式操作沿用现有逻辑，只作用于活动行或正文选区。
- 切换唛头时清空选择；正文增删行后过滤已不存在的行 ID。

### 最近预览历史

`DraftState` 新增 `recentLabels: RecentLabelEntry[]`。每条记录包含：

- 独立历史 ID；
- 完整的 `LabelRecord` 深拷贝；
- 对应 `SizePreset` 深拷贝，保证以后修改尺寸预设不会改变历史；
- 用于去重的稳定签名；
- 最近进入打印检查的时间戳。

最多保存 20 条。相同内容、样式、文字行方向/位置、打印区域、尺寸和数量的唛头再次进入预览时，只更新时间并移动到首位。历史记录不保存图片文件句柄；图片唛头仅在其现有本地 `imageFallback` 可用时进入历史。

旧草稿没有 `recentLabels` 时补为空数组。现有 `needsReview` 和 `reviewReason` 字段继续兼容读取，避免草稿迁移破坏，但业务逻辑、打印验证和界面不再依赖它们。

### 打印预览旋转

`App` 保存临时的 `printRotations: Record<string, 0 | 90 | 180 | 270>`，键为唛头 ID。旋转只属于当前打印检查会话：关闭检查窗口后清空，不写入草稿、历史或原始 `LabelRecord`。同一唛头生成的所有打印份数共享同一角度。

## 界面与交互

### 唛头列表与数量

- 板块标题由“校对清单”改为“唛头清单”，副标题只显示记录数量。
- 移除“待校对/可打印”徽标。
- 每条唛头名称下方放置紧凑数量控件，包含减号、带可访问名称的数字输入和加号。
- 控件把数量限制在 `1..MAX_LABEL_QUANTITY`；按钮在边界禁用。输入期间允许用户编辑，失焦或 Enter 时规范化为合法整数。
- 数量控件阻止点击事件冒泡，不会意外切换当前唛头。
- `LabelEditor` 删除“基础数量”，保留“张贴面数”和“最终打印 N 张”。

### 多行选择与批量编辑

- 预览中被选择的每一行使用相同的实线高亮；活动行额外显示缩放控制柄。
- 右侧行选择按钮支持累加选择并同步高亮，文案改为“已选 N 行”或当前第 N 行。
- 修改字体、字号、粗体、斜体、下划线或横排/竖排时：若有多行选择，对所有选择行应用；否则维持现有活动行/正文选区行为。
- 拖动或用方向键移动任意已选行时，所有选择行使用相同的百分比位移，保持相对位置。
- 整组移动的允许位移取所有选择行可移动范围的交集，确保不会把任何行的锚点移出 `0..100%`。
- 双击文字仍只编辑该行文字；多行选择不合并正文。
- 单击打印区域空白清空选择；拖动打印区域边框或调整打印区域大小不触发清空。

### 使用历史

- “使用过的唛头”显示最近 20 条，按最近进入打印检查的时间倒序。
- 每项显示第一行摘要、尺寸、打印数量和来源，并提供“再次使用”。
- “再次使用”深拷贝历史唛头，生成新的唛头 ID 和文字行 ID；如尺寸预设不存在则先补建历史尺寸预设，再将新唛头加入当前列表。
- 打开单条“打印预览”时记录当前合法唛头；点击顶部“检查并打印”时记录打印计划中全部合法唛头。包含错误的阻塞项不写入历史。
- 写入历史和草稿失败只显示本地保存状态，不阻止当前打印检查窗口打开。

## Excel 框选合并

“框选区域”模式保留多个框选框，但确认导入时只创建一条唛头：

- 按框选创建顺序处理区域；
- 每个区域内部按从上到下、从左到右读取非空单元格；
- 单元格之间用换行连接；
- 区域之间同样用一个换行连接，不额外插入空行；
- 全部区域都为空时不创建唛头并显示现有错误反馈；
- 新唛头数量为 1、张贴面数为 1，来源为 Excel。

“按列批量导入”模式不变。

## 自动缩小排版

现有固定字号在内容过长时直接报错。新布局求解器把用户字号视为每行上限：

1. 对每条非空文字行确定上限：行内字号覆盖值优先，否则使用全局字号。
2. 从上限向下搜索，找到在该行方向、字体、样式、当前锚点和打印区域可用边界内完整显示的最大字号。
3. 未超出时返回原字号，不放大短内容。
4. 多行各自求得字号后检查重叠；自动排列产生的正常行不应重叠。用户手动把多行拖到重叠位置时继续报告重叠错误，不擅自改变位置。
5. 任一行在尺寸预设最小字号下仍无法显示时，打印验证继续阻止该唛头。

布局结果新增按行 ID 索引的字号映射。`LabelPreview` 和 `PrintPages` 都使用该映射，逐行方向仍由 `textOrientation` 决定。

## 打印预览文字旋转

### 预览控制

- 打印检查窗口在每个唯一的文字唛头旁显示小型打印缩略图、当前角度和“旋转 90°”按钮。
- 每次点击按 `0° → 90° → 180° → 270° → 0°` 循环。
- 图片唛头不显示文字旋转按钮，继续按原方向打印。
- 旋转结果立即反映在缩略图中；点击“打印这一组”时把该组所有唛头的当前角度传给打印页。

### 打印渲染

- 保留 `@page { size: Wmm Hmm; margin: 0; }`，纸张物理宽高与方向始终由唛头尺寸决定。
- `PrintPages` 对每条 `.print-positioned-text` 在现有锚点平移之后追加当前预览角度，例如 `translate(...) rotate(90deg)`。
- 角度围绕每条文字行自己的锚点生效，因此纸张、打印区域和行锚点位置不旋转；只有文字字形方向变化。
- 原有 `textOrientation` 继续决定行内横排或竖排，打印预览角度作为外层旋转叠加其上。
- 0° 时生成与当前版本相同的打印 DOM，不引入额外缩放。
- 90°/270° 时自动缩小算法使用旋转后的宽高检查边界；若在允许的最小字号下仍无法放入纸张，则该角度在预览中显示溢出提示，并禁用对应打印组按钮，用户可继续旋转或返回编辑。
- 打印检查窗口继续提示用户选择完全相同的自定义纸张、缩放 100%、边距为无，并明确不要在系统窗口交换纸张方向。

## 打印资格与“校对”移除

`validateLabelForPrint` 不再检查 `needsReview`。以下验证继续存在：

- 文本内容非空或图片可用；
- 打印数量和张贴面数为正整数且不超过现有限额；
- 尺寸预设合法；
- 逐行排版在允许的最小字号下可完成；
- 单条及总打印张数不超过现有限额。

`draftReducer` 更新正文、数量或面数时不再写入新的校对原因。复制、导入和手动新增不再需要人工确认状态。旧字段可在后续独立迁移中删除，本轮不改变草稿版本号。

## 错误处理与可访问性

- 数量输入具有每条唛头独立的可访问名称，错误值在控件附近提示。
- 多行选择使用 `aria-pressed` 暴露状态；样式区域通过状态文案公布选择行数。
- 方向选择的名称明确为“所选行方向”或“第 N 行方向”。
- 打印检查仍列出所有真正阻止打印的问题，并提供“去修改”。
- 历史恢复使用新 ID，避免 React 键和草稿记录冲突。
- 本地存储水合时深拷贝历史快照并过滤损坏、缺少内容或尺寸非法的条目。

## 组件与文件边界

- `src/domain/textLines.ts`：多行批量样式/方向、整组移动和 ID 重建。
- `src/domain/layout.ts`：逐行最大可用字号求解与统一布局结果。
- `src/domain/history.ts`：历史签名、记录、去重、20 条限制和恢复副本。
- `src/domain/importing.ts`：多区域合并为一条唛头。
- `src/domain/printing.ts`：打印计划中的合法唛头提取和每个文字唛头的预览旋转状态。
- `src/domain/draft.ts`、`src/domain/storage.ts`：历史持久化、旧草稿兼容、移除校对状态副作用。
- `src/features/LabelList.tsx`：行内数量控件和去除校对徽标。
- `src/features/LabelEditor.tsx`：多行样式操作和删除基础数量。
- `src/features/LabelPreview.tsx`：连续选择、空白清除、整组拖动和统一字号映射。
- `src/features/SourceHistory.tsx`：最近 20 条历史与再次使用。
- `src/features/PrintPages.tsx`：固定纸张画布、逐行文字旋转和统一逐行布局。
- `src/features/PrintReviewDialog.tsx`：打印缩略图、循环旋转控制、纸张方向说明与历史记录入口的呈现。
- `src/App.tsx`：临时选择状态、临时打印旋转、历史记录时机和各组件编排。

## 测试与验收

### 领域测试

- 多行批量样式和方向只修改选择行。
- 整组拖动保持相对位置并正确限制边界。
- 历史签名去重、更新时间、最多 20 条、恢复时重建所有 ID。
- Excel 多框选按选择顺序合并为一个唛头；按列模式保持不变。
- 长内容从用户字号向下缩小到最大可用字号；短内容保持原字号；最小字号仍失败时返回阻塞错误。
- 打印验证忽略旧 `needsReview`，仍阻止真正无效的数据。
- 0°、90°、180°、270° 循环正确；旋转后的文字边界参与排版验证，纸张宽高不变。

### 组件测试

- 列表数量加减、直接输入、边界和阻止行点击冒泡。
- 连续选择多行、空白清除、批量方向/样式和整组键盘移动。
- 编辑器不再渲染“基础数量”和校对文案。
- 打开单条或全部打印检查时记录正确的合法唛头。
- 历史列表显示最多 20 条并能再次使用。
- 打印缩略图和打印 DOM 使用同一旋转角度及逐行字号映射；关闭窗口后旋转状态清空。

### 浏览器验收

- 桌面视口验证列表数量、多行选择、整组拖动、历史恢复和 Excel 框选合并。
- 窄屏验证数量控件、历史列表和打印检查窗口不溢出。
- 在打印检查中循环验证 0°、90°、180°、270°：文字角度与实际打印一致，纸张宽高、打印区域和行锚点不变。
- 检查控制台无错误，刷新后历史和数量仍保留。
