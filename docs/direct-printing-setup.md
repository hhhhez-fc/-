# XP-420B 直接打印操作指南

本指南供 Windows 仓库操作员使用。正常流程在网站的“直接打印标签”对话框内完成，不会打开浏览器打印窗口。首个受支持配置是 Xprinter XP-420B、203 DPI、`100 × 75 mm` 标签纸；最终输出固定为 `800 × 600` 黑白位图。

> 安全提示：只使用内部发布负责人提供的安装包和 SHA-256。不要在聊天、工单、截图或日志里发送配对凭据、标签内容、业务文件、密码、令牌、私钥或证书文件。当前仓库尚未产出可分发安装器，实体 XP-420B 验收也尚未完成；本文不代表硬件已获生产批准。

## 1. 下载与首次手动安装

1. 从内部发布页下载 `LabelPrintHelper-Setup.exe`，同时取得该版本公布的 SHA-256。没有发布页和校验值时，停止安装并联系维护人员。
2. 在文件属性中确认发布者与版本符合内部发布说明，并用 Windows PowerShell 核对哈希：

   ```powershell
   Get-FileHash -LiteralPath '.\LabelPrintHelper-Setup.exe' -Algorithm SHA256
   ```

   输出必须与发布说明逐字一致。不要使用来路不明、哈希不一致或被浏览器改名的安装包。
3. 双击安装包并按 Windows 提示完成当前用户安装。助手安装在当前用户目录，不要求另装 .NET Runtime；安装过程会注册当前用户登录启动和 `labelprint://` 启动协议。
4. 安装结束后允许启动 **Label Print Helper**。正常运行时它驻留在 Windows 通知区域；关闭诊断窗口只会隐藏窗口，不会退出后台助手。
5. 回到网站，打开“检查并打印”，再按“刷新连接”。若仍显示“未检测到打印助手”，按网站的“启动/打开打印助手”，或从开始菜单启动 **Label Print Helper**；处理浏览器的外部协议提示后，再按“刷新连接”。网站只能发出启动请求，不能确认助手是否实际打开。

首次安装、证书信任提示和实际安装器冒烟测试必须由发布负责人在目标 Windows 环境完成。本指南不要求操作员绕过浏览器或 Windows 安全警告。

## 2. 首次配对

1. 打开网站的“直接打印标签”对话框。状态显示“需要在打印助手中完成配对”时，查看通知区域或已弹出的“网站打印配对”窗口。
2. 在助手窗口核对申请来源确实是正式网站；来源不符时选择拒绝并联系维护人员。
3. 批准配对后回到网站，按“检查配对状态”。状态应变为“打印助手已连接”。
4. 配对被拒绝、过期、已被领取或授权失效时，按“刷新连接”重新发起一次配对。不要复制、记录或转发配对凭据。

配对只授权已核对的网站与本机助手通信。清除浏览器站点数据、换浏览器或卸载后重装都可能需要重新配对。

## 3. 选择 XP-420B 与传感器校准

1. 确认 XP-420B 已通过 USB 连接，Windows 打印队列名称中包含 `XP-420B`，并且队列没有暂停或脱机。
2. 在网站“打印机”下拉框选择可用的 XP-420B。网站会记住当前浏览器最近选择的打印机。
3. 装入 `100 × 75 mm` 标签纸，确认纸卷类型是间隙纸、黑标纸或连续纸。介质类型、间隙/黑标高度与偏移必须来自纸张说明或现场测量，不要凭经验猜测。
4. 在网站按“校准打印机”。网站会用固定的 `labelprint://calibrate` 请求打开助手并聚焦校准控件；协议不携带打印机标识、标签内容或其他业务数据。浏览器可能要求确认打开外部应用，也无法确认助手是否真的打开或校准完成；必要时从 Windows 通知区域手动打开“诊断与校准”。
5. 在助手中选择同一台打印机和正确介质参数，然后按“执行纸张校准”。校准命令本身不会打印标签。
6. 观察走纸是否符合所选传感器类型。若走纸异常，停止后续操作，重新核对介质与参数。

## 4. 实体边框确认（生产配置门槛）

边框测试会真实消耗一张标签并直接发送到所选打印机。只有现场具备目标 XP-420B 和 `100 × 75 mm` 介质时，才可执行：

1. 在助手诊断窗口按“打印 100 × 75 mm 边框并验证”，确认一次显式测试打印。
2. 实体输出必须恰好是一张标签，四边完整、未被裁切、未跨到第二张，也没有额外空白走纸。
3. 只有全部条件都满足时，才在助手的确认框选择“是”。任何不确定、裁边、偏移或跨标签都选择“否”；配置会保持未验证，正式直接打印继续被阻止。
4. 未通过时依次检查介质类型、间隙/黑标参数、装纸位置和打印机传感器，再重新执行校准与边框测试。不要用缩小字号绕过物理问题。
5. 通过并在助手中确认后，回网站按“刷新连接”。网站会重新读取当前打印机的校准状态；“校准未验证”提示消失且“直接打印”可用，才可继续。不要把浏览器成功唤起助手误当成校准通过。

更换纸卷类型、传感器设置或重新测试时，既有已验证状态会先被撤销；新测试失败或取消后不会自动恢复。

## 5. 正常直接打印

1. 在网站完成唛头内容、数量、尺寸、字号、位置与排版检查，按“检查并打印”。
2. 在“直接打印标签”中确认：
   - 状态为“打印助手已连接”；
   - 选择的是可用 XP-420B；
   - 页面不再显示“校准未验证”，且助手中已完成实体边框确认；
   - 标签规格是固定的 `100 × 75 mm`；
   - 打印范围正确；
   - 打印份数在 `1–100`，需要时再启用“逐份打印”；
   - 横向/纵向、文字旋转、水平/垂直偏移（`-10..10 mm`）和黑白阈值符合预期；
   - 右侧最终位图逐张检查无越界，页数公式与实际需求一致。
3. 按“直接打印”一次。网站会依次显示生成、上传和提交状态；忙碌期间不要重复点击、刷新或关闭页面。
4. 出现“已向打印队列提交 N 张”仅表示任务进入 Windows 打印队列，不等于实体标签已经输出。仍需核对队列和实际纸张数量。
5. 正常“直接打印”不应打开浏览器打印窗口。如果打开了，停止操作并记录不含标签内容的现象、版本与时间，交给维护人员排查。

## 6. 离线、部分提交与状态不明

### 助手或打印机离线

- “未检测到打印助手”：按“启动/打开打印助手”或从开始菜单启动，等待通知区域图标出现，再按“刷新连接”。浏览器仅能发出外部协议请求；不要因没有自动反馈而直接改用浏览器打印。
- “版本不兼容”：停止直接打印，按内部发布流程下载并手动安装匹配版本；不能跳过版本检查。
- “未发现可用且兼容的 XP-420B”：检查 USB、电源、Windows 队列名称、暂停/脱机状态，再刷新连接。
- “校准未验证”或校准状态读取失败：按“校准打印机”打开助手，完成校准、边框测试和实体确认，再回网站“刷新连接”；状态明确为已验证前，“直接打印”保持禁用。

### 明确失败

若页面明确说明任务未提交，可修正打印机、连接、排版或参数后重新直接打印。不要把原始错误、业务标签或配对信息粘贴到公开渠道。

### 部分提交

1. 先检查实体输出与 Windows 打印队列，对照网站显示的“已提交实体标签”页码。
2. 不要重新发送整个范围。
3. 确认后使用“从第 N 张创建新任务”，只处理未确认部分；新任务仍需重新核对范围和总数。

### 状态不明

1. 不要自动重试，也不要立即再次按“直接打印”。
2. 先检查打印机已出的实体标签和 Windows 打印队列，记录已确认页码。
3. 确认边界后再使用“从第 N 张创建新任务”。无法确认时停止打印并请维护人员按任务 ID 查询状态，避免重复标签。

### 页面刷新或重启后

重新打开网站并刷新助手连接。网站应按原任务 ID 查询状态；在状态明确前不要盲目创建相同任务。Windows 重启后若助手未自动连接，从开始菜单启动后重试，并把启动项问题报告给维护人员。

## 7. 手动升级

1. 完成当前任务并确认 Windows 打印队列没有待处理的 Label Print Helper 作业。
2. 从内部发布页下载新版安装包和对应 SHA-256，按第 1 节核对文件与哈希。
3. 退出或按发布说明关闭旧版助手，再运行新版安装包。不要同时运行两个版本。
4. 安装后打开网站，按“刷新连接”，确认版本不兼容提示消失；需要时重新配对。
5. 若升级涉及打印配置或纸张配置版本，重新执行传感器校准和实体边框确认。升级说明没有明确豁免时，按需要重新验证处理。

第一版没有自动升级。不要让脚本或第三方下载器替你安装新版。

## 8. 浏览器打印（仅应急）

只有直接打印暂时不可用、现场明确接受跨标签风险并决定继续时，才使用：

1. 在直打对话框展开“更多操作”，选择“浏览器打印（应急）”。
2. 阅读风险说明，再按“仍然打开浏览器打印”。取消不会改变草稿。
3. 在系统打印窗口选择 XP-420B、自定义 `100 × 75 mm`、与网站一致的方向、100%/实际大小、无边距，并将系统打印份数保持为 1。
4. 先打印一张无敏感内容的测试标签并确认没有跨纸，再处理业务标签。

浏览器打印会重新经过浏览器、Windows 驱动和纸张设置，不受 `800 × 600` 直打位图的单一几何约束。它不是正常流程，也不能作为直接打印或硬件验收通过的证据。

非 `100 × 75 mm` 分组没有网站直打支持；其分组按钮同样明确标为“浏览器打印（应急）”，第一次点击只显示上述拆分风险，必须再按“仍然打开浏览器打印”才会打开系统界面。

## 9. 完整卸载

1. 确认没有正在提交的任务，Windows 打印队列中也没有待处理的 Label Print Helper 作业。
2. 打开 Windows“设置 → 应用 → 已安装的应用”，卸载 **Label Print Helper**；也可使用开始菜单中的“卸载 Label Print Helper”。
3. 卸载器会先安全停止当前用户助手，再清理本产品创建的 localhost 证书、当前用户登录启动项、`labelprint://` 注册和暂存任务。若停止或清理失败，卸载会取消；关闭助手后重试，不要强制删除正在运行的程序文件。
4. 如需连同保存的配对和打印机校准配置一起完全移除，卸载成功后手动删除 `%LOCALAPPDATA%\LabelPrintHelper`。此操作不可恢复；确认目录路径完整且只指向该产品后再删除。
5. 在浏览器开发者工具的 Application/应用 → Local Storage 中，只删除正式网站下的以下两个键：
   - `label-printing-local:print-helper-token:v1`
   - `label-printing-local:selected-printer:v1`

   不要清除整个站点数据，除非已导出并确认可以丢弃本地草稿、历史和业务设置。
6. 重启浏览器，确认网站显示“未检测到打印助手”或要求重新安装/配对；Windows 登录后确认助手没有再次启动。

若卸载后仍有产品证书、启动项或协议注册残留，不要手工修改注册表或证书库；记录不含敏感内容的现象并交给维护人员处理。

## 10. 验收与问题记录

生产启用前必须由授权人员在真实 XP-420B 与 `100 × 75 mm` 纸张上记录：边框校准、1 条→1 张、10 条→10 张、多行/最大字号/边框/旋转/图片/正负偏移、两份逐份与非逐份、离线/缺纸/断开/部分/未知恢复、Windows 重启/自启动/重连，以及全程正常直打不出现浏览器打印窗口。

若单条内容仍跨两张标签，停止生产启用，并按 `800 × 600 PNG → packed bitmap → TSPL SIZE → 传感器配置 → spool bytes → 实体校准` 找到第一个不一致边界。只保存不含业务内容的任务摘要、PRN 证据，以及操作员明确提供的照片或日志。
